# 活动管家操作手册

本手册面向管理者、参与者和公开报名者。环境启动见 [DEPLOYMENT.md](DEPLOYMENT.md)，接口细节见 [API.md](API.md)。示例使用测试成员和测试活动，QQ 为可选渠道。

## 1. 初始化与登录

1. 打开部署入口；默认启动脚本为 `http://127.0.0.1:18080/`，单机通常为 `http://127.0.0.1:8080/`。
2. 第一次访问填写管理者登录名、姓名、组织名称和密码，阅读并同意隐私政策，完成初始化。
3. 已初始化时使用账号密码登录。成员账号由管理者创建或导入，初始/重置密码登录后先到“设置”修改，再重新登录。
4. 会话失效时在原页面重新登录，检查保留的输入，再手动重试。普通无权访问提示需要核对账号权限。

## 2. 管理者：班级与成员

进入“成员管理”，创建并选择班级。下载 Excel 模板，按模板填写后导入；整批校验失败时先修正提示的行。妥善交付成员初始登录信息，初始密码以导入文件为准。已有用户名可能因组织归属或账号状态不符合条件被拒绝，不能通过重复导入跨组织接管账号。

QQ 使用顺序：到“设置”取得绑定命令，在目标群完成机器人绑定；回到“成员管理”刷新授权群，选择并保存班级通知群。无机器人配置时可先使用平台业务；绑定已失效时重新核对组织授权。

## 3. 管理者：生成、修改和发布

1. 进入“AI助手”，选择目标班级，描述作业、通知、问卷或活动。
2. 查看生成的草案类型、模型/离线说明、检索来源和结构化内容。离线建议可能缺日期，需人工补充。
3. 修改标题、说明、日期、题目和工作流；复杂活动核对任务、真实负责人和物料。姓名相同不能代替账号身份。
4. 保存并确认发布。简单事务进入相应待办；复杂活动进入“活动管理”的详情。
5. 若显示“等待补充”，按缺失项填写并保存后继续；失败时阅读步骤与安全错误再重试。发布后的草案只读，勿重复创建来代替恢复。

“业务模板”可以选择内置/本组织模板，或从自己的草案、活动提取通用结构。编辑后应用到班级只会生成新草案，仍需检查日期、负责人及发布内容。

## 4. 作业与待办

参与者在“总览”或“作业与待办”选择本人待办，填写完成说明并按需上传文件，确认提交后检查状态。上传大小、文件类型和配额受服务端限制；失败时根据提示调整。

管理者在“作业与待办”查看已交/未交名单、提交说明和授权文件，按需催办、设置提醒或导出未交 CSV。活动任务可在总览和任务区域更新本人状态；有前置依赖时先完成依赖。管理者在活动详情处理待分配任务、改派、期限和优先级。

## 5. 公开报名与回执

管理者从活动详情打开或分享报名入口；公开报名者无需账号，按题目填写姓名、联系方式及扩展回答。满额、截止或关闭时按页面提示处理。

报名成功后保存回执编号及取消凭证。本设备保留回执，也可展开“使用保存的回执查看或取消报名”手工填写。确认取消后释放名额；不要把取消凭证交给他人。回执丢失时联系活动负责人，不应尝试读取其他报名者资料。

创建者在详情查看统计与完整回答、调整容量/截止/开放规则并导出报名 CSV。CSV 可用表格软件打开，权限与统计以当前活动状态为准。

## 6. 签到与反馈

创建者在活动详情开放签到/反馈并保存，就绪活动会把当前有效成员加入成员快照。新成员加入班级后需再次保存开放设置；成员离班后历史记录保留。管理区可筛选到场/缺席、为合资格成员代签并查看评分分布，反馈原文在授权区域展开。

成员在“签到与反馈”选择活动，开放时确认本人签到。当前有效、已进入快照且已签到的成员才可提交 1–5 分和文字意见，也可在开放期间修改自己的反馈。失败时输入保留，版本冲突应先刷新并核对已保存内容。

结束活动后不再新签到，也不追加成员快照；反馈仍可按开放设置提交。取消活动不接受新提交。反馈原文仅用于授权业务查询，复盘模型接收聚合统计。

## 7. 活动管理、复盘和结束

活动详情展示执行步骤、报名、任务、提醒、投递及变更记录。改期前检查新日期和报名截止，保存后核对日历与提醒。ICS 可下载到个人日历；变更后的日历保留 UID 和版本。

生成复盘时查看数据库统计快照、版本、正文和降级说明，刷新后可查历史。生成复盘不会结束活动；确认活动结束须另行操作，结束会关闭报名、签到及未发送提醒。整体取消会阻止后续执行，但已经发送或在途的通知有独立事实。

QQ 投递若为未知结果，先核对网关记录，再根据页面允许的动作处理，避免连续点击重发。业务变更成功而通知失败时使用变更通知重试，不要重复修改活动。

## 8. 知识库与个人设置

管理者在“知识库”维护本组织资料、编辑或删除并查看检索来源；公共资料只读。历史向量来源未知时按提示编辑保存重新索引。

“设置”提供改密、QQ 状态、隐私政策、个人数据导出、注销及管理者审计入口。改密后需重新登录；注销前先确认页面提示与需要保存的个人资料。课程提交和截图请使用测试数据。

遇到无权限先核对当前账号、组织和活动创建者；页面数据读取失败使用刷新/重试。部署与依赖故障由运维按部署手册定位，本手册不代表实网 QQ 或恢复验收已完成。
