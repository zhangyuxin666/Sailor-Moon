# Character artwork attribution

Original pixel artwork from the Universal LPC Spritesheet Character Generator.

Source: https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator

Files are downloaded without image modifications. The application composites 64px frames and recolors layers at runtime; rendered variations inherit the applicable artwork license. No Stardew Valley game character files are included.

Per-file credits and source links: CREDITS.csv. Asset paths: sources.json.
